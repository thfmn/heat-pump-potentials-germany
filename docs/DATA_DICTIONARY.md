# Data Dictionary

This document describes the data structures, columns, and value definitions used in the Heat Pump Potentials Germany application.

## CSV Column Descriptions

The district-level CSV files are stored in `webapp/data/districts/` with one file per German federal state. Each CSV file follows the naming convention `{state_abbrev}_full_data.csv`.

| Column | Data Type | Description |
|--------|-----------|-------------|
| (index) | Integer | Row index (0-based), auto-generated by pandas |
| `district` | String | Name of the district (Landkreis or Kreisfreie Stadt), e.g., "Ingolstadt, Kreisfreie Stadt" |
| `building_type` | Integer | Numeric code identifying the building category. See [Building Type Definitions](#building-type-definitions) for mappings. |
| `heat_source` | Integer | Numeric code identifying the heat pump type. See [Heat Source Definitions](#heat-source-definitions) for mappings. |
| `value` | Float | Heat pump suitability proportion for this district/building/heat source combination. Range: 0.0 to 1.0 |
| `federal_state` | String | Full name of the German federal state (Bundesland), e.g., "Bayern" |
| `district_type` | String | Administrative classification of the district. Values: "Kreisfreie Städte" (independent cities) or "Landkreise" (rural districts) |
| `geometry` | String | Well-Known Text (WKT) representation of the district's geographic boundary. See [Geometry Format](#geometry-wkt-format-explanation) for details. |

### Example Row

```csv
0,"Ingolstadt, Kreisfreie Stadt",100,0,0.7565,Bayern,Kreisfreie Städte,"POLYGON ((11.49... 48.74...))"
```

This row indicates:
- District: Ingolstadt (an independent city)
- Building type: 100 (Total - all building types combined)
- Heat source: 0 (Total - all heat sources combined)
- Value: 0.7565 (75.65% of buildings are suitable)
- State: Bayern (Bavaria)
- District type: Kreisfreie Städte (independent city)
- Geometry: WKT polygon defining the district boundary
